第一次使用
1. 电脑需要安装 Node.js 20 或更高版本：https://nodejs.org/
2. 第一次启动会自动安装公开依赖，需要保持网络连接。
3. 服务启动后会优先打开 Google Chrome；如果没有安装 Chrome，则使用系统默认浏览器。
4. 使用期间请不要关闭启动软件的终端窗口。

更新版本时保留个人数据
1. 更新前先关闭旧版本的终端窗口，再双击新版本启动文件。
2. 新版本继续使用 http://127.0.0.1:3210；同一浏览器里的图片 API、文字 API、课件草稿和课件时光舱会继续保留，不需要复制到新文件夹。
3. 请继续使用原来的浏览器，不要清除该浏览器的网站数据。
4. 如果启动地址变成 3211—3220，说明 3210 被其他程序占用；此时旧配置只是暂时没有显示。关闭占用 3210 的程序并重新启动，新版回到 3210 后即可恢复。
5. 浏览器本地数据不是永久备份。重要课件仍请及时下载 PPT，并用“保存方案”导出 JSON 方案文件。
6. 您自己的个人更新版可以继续读取上述本机数据；发给学员的分享压缩包不会包含您的 API、课件和浏览器存档。

苹果电脑如果提示无法打开
1. 先点“完成”，不要点“移到废纸篓”。
2. 打开“系统设置 → 隐私与安全性”，向下找到刚被拦截的启动文件，点击“仍要打开”。
3. 如果没有“仍要打开”，请打开“01-苹果无法打开-复制这条命令.txt”，完整复制其中一整行命令到终端并按回车。
4. 系统弹出选择窗口后，选择解压后的整个工具箱文件夹。命令会自动解除隔离、添加执行权限并启动软件。
5. 不要只输入 xattr -dr com.apple.quarantine；后面没有路径时会提示 Expected at least 2 but got 1，说明命令没有执行成功。

API 与参考图
1. 分享包不包含作者的 API 地址和 API Key。
2. 使用悟空API时，先在悟空控制台创建一把“生图组”Key；不要选 Gemini、GPT 或其他对话分组。
3. 打开右上角“接口设置”，API 服务地址只填 `https://wkapi.work`，不需要手动添加 `/api/v1/studio`。
4. 粘贴自己的 API Key，然后点击“检测连接”和“保存设置”。系统会自动补全生图路径，并使用 GPT-Image-2、16:9 横版。
5. 保存后 API 地址和 API Key 会长期保留在当前电脑的当前浏览器，下次打开不需要重填；不会进入方案、PPT 或分享压缩包。
6. 如需移除，请在“接口设置”中点击“清除本机配置”。
7. 参考图生成时会发送到你配置的图片接口；课件生成后会随作品保存在本机“课件时光舱”，不会写入分享方案。
8. 上传参考图后，系统会参考配色、构图和质感并重新创作，不会把原图直接塞进 PPT。
9. 使用参考图需要图片服务支持图生图或图片编辑接口。
10. 软件会自动读取当前电脑的 HTTP 系统代理；如未识别，可在“接口设置 → 高级设置”中手动填写代理地址。
11. 代理设置只保存在当前电脑，不会进入分享方案或 PPT 文件。
12. 模型、尺寸、质量和接口路径均由系统默认或自动推导；更换 API 服务商时，旧的兼容参数会自动清除。

DeepSeek 文字接口
1. 进入“笔记写作”，点击右上角“文字接口”。
2. 点击“一键填写 DeepSeek”，按钮会显示“✓ 已选择 DeepSeek”，软件会立即保存服务商选择并自动填写官方地址、deepseek-v4-flash 和接口协议。
3. 粘贴你自己的 DeepSeek API Key，再点击“检测连接”和“保存设置”。
4. 检测连接会发送一条极短文字请求，会产生少量文字 Token；未填写 Key 时不会发出请求。
5. 旧模型名 deepseek-chat、deepseek-reasoner 已不再作为默认值，软件会提示改用 deepseek-v4-flash 或 deepseek-v4-pro。
6. DeepSeek Key 只保存在当前电脑的当前浏览器，不会进入笔记、PPT 或分享压缩包。

课件时光舱
1. 每生成成功一页，课件会自动保存到右上角“课件时光舱”。
2. 完整课件可以直接重新下载 PPT，不会再次生图，也不消耗 API Token。
3. 未完成课件可以点击“恢复课件”，继续生成剩余页面。
4. 存档只在当前浏览器中有效；更换电脑、浏览器或清除浏览器数据后无法读取。

工具箱四个入口
1. AI 课件：生成一页一张整图的 16:9 PPT。
2. 笔记写作：导入当前课件，填写一个核心关键词；长尾关键词选填且最多 8 个，也可以让文字模型推荐关键词灵感。工具生成标题、种草正文、大字报文案、配图顺序和标签，不生成置顶评论。文字接口与图片接口分开设置，每位使用者填写自己的文字模型 API。
3. PPT 拼图：上传 PPTX，可填写页码范围；留空即提取全部页面。一页一图会快速读取；Windows 上的可编辑多图层 PPT 会调用本机 PowerPoint 渲染完整页面。所有单页均按 16:9 保持比例，并提供两种商品主图：①左侧缩略图＋右侧 3 张重点图；②顶部 1 张主视觉＋下方 3×4 课件矩阵。两种均生成 1080×1440、竖版 3:4 封面，可导出 PNG/JPG。
4. 场景换图：上传场景图后，可一次多选最多 18 张课件页；依次点击左上、右上、右下、左下四个角，之后切换缩略图时会保留四点位置。完成定位后可自定义名称保存为“我的常用场景”，下次一键恢复背景图、四点坐标和画面设置，最多保存 12 个。单张直接导出 PNG/JPG，多张默认一次处理全部图片并打包成 ZIP 下载。

PPT 拼图和场景换图不需要 API。场景换图完全在浏览器本地处理；PPTX 只交给当前电脑上的本地服务读取，不会传到外网。Windows 可编辑 PPT 渲染需要电脑安装并激活桌面版 Microsoft PowerPoint；macOS 建议先导出为图片。
常用场景只保存在当前浏览器，不会进入分享包；更换电脑、浏览器或清除网站数据后需要重新保存。

笔记写作限制
1. 课件原文是唯一事实来源，严格依据模式默认开启且不能关闭。
2. 核心关键词只填一个；长尾关键词可留空，填写时最多 8 个，可用换行或逗号分隔。
3. 工具会检查核心关键词；填写了长尾关键词时再检查长尾覆盖，并明确列出遗漏词。
4. 标题最多 20 字，汉字按 1 字、emoji 按 2 字计算，不使用标点；标题、正文和标签合并在同一个发布文本框中。
5. 课件未提供的价格、效果、销量、评价、资质、时间、服务和收益承诺不得补写。
6. 笔记草稿自动保存在当前浏览器，也可以复制整篇、下载 TXT，或点击“再生成一条”更换写作角度。

AI 课件五步制作流程
1. 页纲内容：整段粘贴“第N页、页面标题、页面文字”，点击“识别页纲”。
2. 参考图片：可选上传一张风格参考图。
3. 逐页要求：可选集中填写每页风格和需要添加的元素。
4. 生成画面：默认同时生成 4 张，也可切换为 2 / 4 / 6 张；每页仍可单独重试。接口繁忙时建议选择 2 张。
5. 导出 PPT：全部页面完成后，导出一页一张整图的 16:9 PPT。

单页重新生成
每张页面卡片底部都有独立按钮。已有图片时点击“再抽一张（替换本页）”，成功后替换当前图片；如果重新生成失败，上一张图片仍会保留。每次点击都会重新调用一次图片 API。

本地地址
通常为 http://127.0.0.1:3210

如果旧版工具还在运行并占用了 3210，新版本会要求先关闭旧版终端，不再自动换端口。这是为了让新版继续读取同一浏览器里原有的 API 配置和课件时光舱。只有 3210 被其他非本工具程序占用时，才会临时使用 3211—3220；此时关闭占用程序并重新启动即可恢复旧数据。

这个地址只代表当前电脑自己。不能把网址单独发给别人使用，请分享整个压缩包。
