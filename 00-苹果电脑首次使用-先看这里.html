苹果电脑首次打开说明

如果双击启动文件后出现“Apple 无法验证是否包含恶意软件”，请按下面步骤处理。只需要首次设置一次。

先点“完成”，不要点“移到废纸篓”。
这是 macOS 对从网络下载、没有苹果开发者签名的本地脚本进行的常规拦截，不代表图片接口出错。

方法一：在系统设置中允许打开

  1. 打开苹果菜单里的系统设置。
  2. 进入隐私与安全性，向下滚动到“安全性”。
  3. 找到刚才被阻止的“苹果系统点这里运行软件.command”，点击仍要打开。
  4. 输入电脑登录密码并确认，然后重新双击启动文件。

方法二：没有“仍要打开”时

  1. 打开 macOS 的终端。
  2. 完整复制下面这一整行命令，粘贴到终端后按回车：
TOOL_DIR="$(osascript -e 'POSIX path of (choose folder with prompt "请选择解压后的mini航海工具文件夹")')" && LAUNCHER="${TOOL_DIR%/}/苹果系统点这里运行软件.command" && xattr -dr com.apple.quarantine "$TOOL_DIR" && chmod +x "$LAUNCHER" && open "$LAUNCHER"
  1. 系统会弹出文件夹选择窗口。请选择解压后的整个工具箱文件夹，然后点击“选取”。
  2. 命令会自动解除隔离、添加执行权限并启动软件，不需要再手动拖入路径。

刚才为什么会提示参数不足？

如果只输入 xattr -dr com.apple.quarantine，后面没有文件夹路径，终端会提示“Expected at least 2 but got 1”。这表示命令没有执行成功。请使用上面完整的一键修复命令。

一键命令仍提示没有执行权限时

  1. 在终端粘贴下面命令，末尾同样保留一个空格。
  2. 把“苹果系统点这里运行软件.command”文件拖进终端，然后按回车。
chmod +x

启动前还需要

电脑需要安装 Node.js 20 或更高版本。安装后再双击启动文件，首次运行会自动安装公开依赖。

打开 Node.js 官方网站

运行成功后会自动打开浏览器。使用期间请保留终端窗口；关闭终端窗口，本地工具也会停止。仍无法启动时，请把终端窗口最后几行文字截图发给工具提供者。
