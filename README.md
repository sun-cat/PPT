# 生财有术mini航海原创PPT课件

作者：舒蓬  
微信：844570

“生财有术mini航海原创PPT课件”是一个本地运行的课件制作工具箱，包含 AI 课件、笔记写作、PPT 拼图和场景换图四个入口。

AI 课件的工作流程是：

1. 一次粘贴整套页面脚本。
2. 自动识别页码、页面标题、页面文字和可选画面提示词。
3. 调用使用者自己的图片生成 API，或本机已登录的 Codex CLI，批量生成整页画面。
4. 把全部图片合成为一页一图的 16:9 PowerPoint。
5. 生成成功的页面自动进入“课件时光舱”，以后可以恢复或重新下载。

导出的 PPT 每页只有一张全屏图片，画布固定为标准 16:9。原始图片比例不一致时，会使用居中覆盖方式，避免拉伸变形。

## 创作工作台

顶部可以直接切换四个工具：

1. **AI 课件**：按照实际制作顺序组织为五步翻页——页纲内容、参考图片、逐页要求、生成画面、导出 PPT。接口设置集中在右上角弹窗中。
2. **笔记写作**：导入当前课件或粘贴资料，用核心关键词锁定方向，长尾关键词选填；生成偏种草、关键词自然的小红书标题、正文、大字报文案、配图顺序和标签。
3. **PPT 拼图**：上传 PPTX，快速读取一页一图课件；遇到可编辑文字、形状或多个图层时，在 Windows 上调用本机 PowerPoint 渲染完整页面，再生成 1080×1440 的小红书商品封面。
4. **场景换图**：上传场景图和课件页面，点击屏幕四角后生成真实四点透视贴图。

四个工具在同一个本地页面内切换，不需要另外安装软件。

## 笔记写作

笔记写作使用独立的文字处理模型 API，与图片生成接口分开配置：

1. 点击“导入当前课件”，自动带入课件名称和完整页纲；也可以直接粘贴其他真实产品资料。
2. 填写一个核心关键词；长尾关键词可以留空，也可以手动填写最多 8 个，或让文字模型根据课件给出关键词灵感。
3. 在课件种草、痛点解决、反差对比、场景体验、清单干货、设计复盘中选择写法，并选择或手动填写目标读者和读者痛点。
4. 默认生成 350–550 字，也可选择 200–350 字或 550–700 字；模型只提炼一个传播角度和 2–4 个代表内容，不逐页复述课件。
5. 标题不得超过 20 字，汉字、字母和数字按 1 字计算，emoji 按 2 字计算；模型会去除标题标点并显示字数。
6. 标题、正文和标签合并在同一个文本框中，不出现“标题、正文、标签”等字段前缀；大字报文案突出有事实依据的反差价值。
7. 工具会检查核心关键词；填写了长尾关键词时再检查长尾覆盖。可以按要求优化，或点击“再生成一条”更换切入角度。
8. 成稿可以直接修改、复制整篇、下载 TXT，并自动保存为当前浏览器的本机草稿。笔记模块不再生成置顶评论。

“严格依据模式”默认开启且不能关闭。课件原文是唯一事实来源；文字模型不得使用外部知识，也不得补写原资料没有的价格、效果、销量、评价、资质、时间、服务和收益承诺。生成结果中的“内容依据”用于人工复核，发布前仍应核对关键事实。

从 AI 课件的第五步也可以点击“用当前课件写笔记”，直接进入笔记工作台。

## 课件时光舱

页面右上角的“课件时光舱”用于保存多份课件作品，不会与单份草稿互相覆盖：

1. 每生成成功一页，当前课件就会自动更新到本机存档。
2. 完整课件可以直接“重新下载 PPT”，只在本地重新合成，不调用图片 API，也不消耗 Token。
3. 制作中的课件可以“恢复课件”，继续补齐未完成页面。
4. 页纲、逐页要求、已生成图片和使用过的参考图会随作品一并保存在当前浏览器。
5. 存档不会上传外网；更换电脑、浏览器或清除浏览器数据后无法读取。

如果本机浏览器存储空间不足，工具会明确提醒。可在时光舱中删除不再需要的作品释放空间。

## PPT 拼图

PPT 拼图支持“一页一张整图”PPTX，也支持常见可编辑多图层 PPTX：

1. 上传 `.pptx` 文件。一页一图会直接快速读取；可编辑 PPT 会自动渲染成整页图片。
2. 可填写提取页码，如 `1-12` 或 `1,3,6-9`；留空表示全部页面。
3. 商品主图提供两种竖版 3:4 版式：①“重点三图”默认用前三页作为右侧三张 16:9 重点大图，其余页面最多取 11 张放入左侧缩略图区；②“主图＋课件矩阵”用 1 张 16:9 页面作为顶部主视觉，下方按页码顺序最多排列 12 张 16:9 课件页。两种版式均使用紧凑拼缝和极小圆角，并保持页面比例不变。
4. 导出 1080×1440、竖版 3:4 的 PNG 或 JPG 商品封面。这里的竖版比例是 3:4，不是横版 4:3。

PPT 页面处理在本地完成，不会访问图片 API。Windows 版检测到文字、形状、图表或多个图片图层时，会调用本机桌面版 Microsoft PowerPoint 以当前页面效果导出 PNG，因此电脑需要安装并激活 PowerPoint。动画会按静态页面状态输出，不会进入拼图。macOS 当前仍建议先在 PowerPoint 中“导出为图片”，一页一图 PPT 不受影响。

## 场景透视换图

场景换图不需要 API，所有处理均在浏览器本地完成：

1. 上传教室、电脑、投影幕布或展示牌场景图。
2. 批量选择一张或多张 PPT 页面、课件封面或商品图片（最多保留 18 张）。
3. 按左上、右上、右下、左下的顺序点击四个角。
4. 四点完成后可拖动编号手柄微调，也可撤销或重新定位。上传多张替换画面后，可点击缩略图或“上一张 / 下一张”切换，四点定位会保持不变。
5. 可调整完整显示/铺满屏幕、透明度、亮度和 0—10px 边缘羽化。
6. 完成四点定位后，可以自定义名称并保存为“我的常用场景”。工具会一起保存原始背景图、四点坐标和画面贴合设置；下次打开后点击“使用”即可恢复，最多保存 200 个，也可以重命名或删除。
7. 只有一张替换画面时直接导出 PNG 或 JPG；上传多张时会默认一次处理全部图片，并按上传顺序打包为一个 ZIP 下载。导出尺寸与原场景图完全一致，编号和选区边界不会进入成品。

如果替换图和屏幕比例不同，默认“完整显示”会保留全部内容并允许出现留边；选择“铺满屏幕”会裁掉少量边缘以填满区域。

常用场景只保存在当前浏览器，不会上传网络，也不会进入分享方案、PPT 或分享压缩包。更换电脑、浏览器或清除网站数据后需要重新保存。

## 页面脚本格式

默认识别以下格式，页面文字可以包含多行：

```text
第1页
页面标题：第一页标题
页面文字：
第一页正文第一行
第一页正文第二行

第2页
页面标题：第二页标题
页面文字：
第二页正文
```

旧方案中的“画面提示词”字段仍然可以继续使用：

```text
画面提示词：
左文右图，深色背景，标题放在左上区域
```

没有填写画面提示词时，系统会根据页面标题和正文自动组织版式。

## 逐页风格与元素

第三步提供一个统一的大文本框，可以集中填写需要特殊处理的页面，不需要逐页打开表单：

```text
第1页
画面风格：明亮、轻松、现代扁平插画
添加元素：指南针、航海路线、绿色标记点

第3页
画面风格：简洁的商业信息图
添加元素：上升曲线、数据卡片、绿色箭头
```

这个文本框可以完全留空。没有写到的页面会根据页纲和参考图片自动设计；修改逐页要求后，受影响的已生成页面会自动恢复为“待生成”，避免导出旧画面。

## 单页重新生成

第四步的每张页面卡片底部都有独立操作按钮。第一次显示“生成这一页”；页面已有图片后显示“再抽一张（替换本页）”。重新生成时会暂时保留当前图片，只有新图片成功返回后才替换；如果请求失败，上一张可用图片不会丢失。每次点击都会重新调用一次图片 API。

## 参考图工作流

主界面提供可选的参考图上传区域，支持 PNG、JPG 和 WebP，单张最大 12 MB。

1. 上传一张相近的产品图、元素图、风格图或构图参考。
2. 上传完成后会自动开启“参考并二创”，不需要再选择模式。
3. 系统会分析构图、配色、主体元素、材质和光影，并结合每页文字重新设计新的 16:9 页面。
4. 默认应用到全部页面；如有需要，可在“可选：指定页面或补充要求”中填写页码和要求。
5. 生成对应页面时，系统会自动调用图片编辑端点并提交参考图。

参考图不是先单独上传到某个分析服务，而是与当前页提示词一起提交给支持图生图/图片编辑的模型。提示词会明确要求模型只参考视觉语言，不复制原图文字、Logo、水印和原始排版。GPT Image 2 可以直接使用参考图生成新的图片；如果需要只替换图片中的某个精确区域，则还需要额外提供蒙版，本版本暂不提供蒙版编辑。

## API 设置与检测

图片 API 配置集中在 AI 课件页面右上角的“接口设置”弹窗，不会长期占用主界面。切换到“笔记写作”后，右上角会改为“文字接口”。

### 本机 Codex 生图

接口类型选择“本机 Codex · 已登录账号”后，工具会直接调用这台电脑上的 Codex CLI，不需要填写图片 API 地址或 API Key。

使用前需要确认：

1. 终端可以运行 `codex`，并且 Codex CLI 已更新到支持当前模型的版本。
2. 已通过 `codex login` 登录 ChatGPT 账号。
3. 点击“检测连接”确认 CLI、登录状态和 `image_generation` 功能可用。检测过程不会生成图片。

实际生图会启动一次临时、隔离的 Codex 任务，并使用内置 `$imagegen` 能力。每个任务只允许读写自己的系统临时目录；参考图会临时写入该目录，生成完成或失败后自动删除。工具不会读取或保存 Codex 登录 Token，也不会把图片 API Key 传给 Codex 子进程。批量生成固定串行执行，避免多个 Codex 生图任务同时争用本机资源。实际生成会计入当前 ChatGPT/Codex 账号的使用额度。

### 火山方舟豆包生图

接口类型可选择“火山方舟 · 豆包 Seedream 生图”。工具会自动使用官方图片接口
`https://ark.cn-beijing.volces.com/api/v3/images/generations`，并支持纯文字生图和参考图生图。

学员只需要填写自己的火山方舟 API Key，并选择已开通的 Seedream 图片模型；内置选项包括
Seedream 5.0 Lite、5.0、4.5、4.0，也可以填写控制台提供的图片 Model ID 或 Endpoint ID（`ep-...`）。
工具不会展示或调用 Seedance 视频模型，并固定关闭组图模式，一次请求只生成一张 16:9 课件图。

普通使用者只需要填写两项：

1. 图片生成 API 地址（通常是以 `/v1` 结尾的 Base URL）。
2. API Key。

模型、画面尺寸、生成质量、检测地址、参考图编辑地址和网络代理均已提供默认值或自动推导，不需要学员逐项设置。更换 API 服务商时，工具会按域名识别服务商变化，自动清除上一家服务商遗留的检测地址、编辑地址和额外请求参数，避免新 Key 被误发到旧接口。

点击“保存设置”后，API 地址、API Key 和高级设置会长期保存在当前电脑的当前浏览器，下次打开工具不需要重新填写。它们不会进入课件方案、PPT 或分享压缩包。需要移除时，点击接口弹窗中的“清除本机配置”。

文字接口优先提供 DeepSeek 一键配置：点击“一键填写 DeepSeek”后，工具会立即保存服务商选择、显示“✓ 已选择 DeepSeek”，并填入官方地址 `https://api.deepseek.com`、笔记推荐模型 `deepseek-v4-flash`，自动使用 `/chat/completions`；使用者只需粘贴自己的 DeepSeek API Key。未填写 Key 时不会关闭弹窗或误报配置成功。DeepSeek 旧模型名 `deepseek-chat`、`deepseek-reasoner` 会收到明确的升级提示。其他兼容服务仍可填写自己的 Base URL、模型和 Key，并在高级设置中选择 Responses API 或 Chat Completions。更换文字 API 服务商域名时，旧 Key 和额外请求头会立即清除，防止凭证误发到新的服务商。

“检测连接”会实际发送一条极短的文字请求，用于同时验证地址、模型、鉴权和返回内容，因此会产生少量文字 Token。没有填写 DeepSeek Key 时，工具会在本机直接拦截，不会向接口发送请求。

填写接口后可以点击“检测连接”。工具会：

- 自动从标准图片生成地址推导 `/v1/models` 检测地址。
- 检查服务器是否可访问。
- 检查 API Key 鉴权是否通过。
- 显示响应时间和检测结果。
- 自动读取 Windows 或 macOS 当前启用的 HTTP 代理，让本地后台与浏览器使用相同网络线路。
- 允许在高级设置中手动填写代理地址；留空时自动检测，没有代理时保持直连。
- 允许在高级设置中填写服务商指定的独立检测地址。
- 上传参考图后，自动从 `/images/generations` 推导 `/images/edits`；服务商路径不同可以单独填写“参考图编辑 API 地址”。
- 识别到悟空API域名或 `/api/v1/studio` 路径时，自动改用创作台 `/catalog` 做无费用检测。学员界面只需填写 `https://wkapi.work`，完整 Studio 路径由系统内部补全。

连接检测不会生成图片；如果服务商没有模型列表接口，系统会提示“服务器可访问”，最终以实际生成为准。

如果直连失败但系统代理可用，检测结果会明确显示“已使用网络代理”。代理地址只用于当前电脑的 API 请求，不会进入分享方案或 PPT 文件。

## 隐私原则

项目中没有内置作者的 API 地址或密钥。图片生成可以使用自己的图片接口，也可以复用本机已登录的 Codex；文字处理仍需配置自己的文字接口。

- API 地址、API Key 和高级连接参数保存在当前浏览器的本地存储中，直到使用者主动清除；不会进入方案、PPT 或分享包。
- 文字 API 地址、文字模型、Key 和兼容参数独立保存在当前浏览器，不会进入笔记草稿、下载文本或分享包。
- 笔记生成时，只会把当前课件依据、关键词和写作条件发送给使用者自己配置的文字接口。
- 参考图片生成时会发送到使用者配置的图片接口；课件生成后会作为该作品的一部分保存在本机“课件时光舱”。
- 选择本机 Codex 时，页纲、逐页要求和可选参考图会交给本机 Codex CLI；参考图与任务工作目录会在任务结束后自动删除，最终图片仍会保存在本机“课件时光舱”。
- PPT 拼图上传的 PPTX 只发送到当前电脑上的 `127.0.0.1` 本地服务进行解包，不会发送到外网。
- 场景换图的场景图和最多 18 张替换画面完全在浏览器本地处理，批量导出 ZIP 也在本机生成，不会发送到图片接口或其他网站。
- 高级请求参数和额外请求头会随 API 设置保存在当前浏览器，但不会写入课件草稿、方案或 PPT。
- 网络代理地址只保存在当前电脑，不会进入导出的课件方案。
- “保存方案”不会导出 API 地址、模型、请求头、Key、参考图或生成图片。
- “课件时光舱”使用浏览器本地数据库保存多份作品和图片，不会访问图片 API；重新下载只调用当前电脑的 PPT 合成功能。
- 本地 `.env` 已被 `.gitignore` 排除。
- 分享包不会包含 `.env`、浏览器草稿或测试输出。

## 双系统启动

Windows 使用者双击：

```text
Windows系统点这里运行软件.bat
```

苹果电脑第一次使用先打开：

```text
00-苹果电脑首次使用-先看这里.html
```

如果已经出现 Gatekeeper 拦截，也可以打开根目录的 `01-苹果无法打开-复制这条命令.txt`，把其中完整的一键修复命令粘贴到终端。命令会弹出文件夹选择窗口；选择解压后的整个工具箱文件夹后，会自动执行 `xattr`、`chmod` 并打开启动器。不要单独执行没有文件夹路径的 `xattr -dr com.apple.quarantine`，否则会提示参数不足且不会解除隔离。

按照页面提示处理 macOS 的 Gatekeeper 安全拦截后，再双击：

```text
苹果系统点这里运行软件.command
```

两个启动文件都会等待本地服务启动完成，然后自动打开软件。Windows 会优先使用 Google Chrome；如果电脑没有安装 Chrome，才使用系统默认浏览器。使用期间请保留终端窗口；关闭窗口后，本地服务也会停止。

Windows 脚本会优先使用系统中的 Node.js；如果电脑安装了 Codex 桌面版，也会自动尝试 Codex 内置运行环境。macOS 需要提前安装 Node.js 20 或更高版本。由于 `.command` 是未经过苹果开发者签名的本地启动脚本，从微信或浏览器下载后可能被 Gatekeeper 首次拦截；首次使用页提供“隐私与安全性 → 仍要打开”以及 `xattr` 终端备用处理方式。启动器会核对正在运行后台的版本；如果 `3210` 被本工具的旧版本占用，新版会要求先关闭旧版终端，不再自动换端口，以便继续读取相同浏览器来源下的 API 配置和课件时光舱。实际地址通常是：

```text
http://127.0.0.1:3210
```

普通电脑请先安装 [Node.js 20 或更高版本](https://nodejs.org/)，也可以手动运行：

```powershell
npm install
npm start
```

### 关于 `127.0.0.1`

- `127.0.0.1` 也叫 localhost，固定代表“正在使用的这台电脑自己”，不是家庭或公司的公网 IP，也不是可供外部访问的域名。
- `3210` 是本工具固定优先使用的端口；更新前请先关闭旧版本终端，新版本会继续读取该地址下的浏览器数据。
- 把 `http://127.0.0.1:3210` 单独发给别人，对方无法访问你电脑上的工具。
- 正确的分享方式是把工具压缩包发给对方。对方解压后，根据自己的系统双击对应启动文件，会访问对方电脑上的 `127.0.0.1` 本地地址。
- 本工具只监听本机地址，不接受局域网或互联网中的其他设备直接访问。
- 如果旧版工具仍占用 `3210`，启动器会明确提示先关闭旧工具，以免换端口后暂时看不到原 API 配置和课件时光舱。只有其他程序占用 `3210` 时才临时选择 `3211`—`3220`。部分公司电脑也可能限制 Node.js 或脚本运行。

## 更新版本与个人数据

API 设置、当前草稿和课件时光舱保存在浏览器针对 `http://127.0.0.1:3210` 的本地数据中，而不是旧工具箱文件夹中。更新时先关闭旧版终端，再从新版文件夹启动，并继续使用原来的浏览器，数据会自动保留。不要清理该浏览器的网站数据。

如果浏览器地址临时变成 `3211`—`3220`，旧数据并未被删除，只是属于 `3210` 的数据在另一个端口不可见。释放 `3210` 并重新启动即可恢复。浏览器本地存储不能代替永久备份；重要作品仍应下载 PPT，并导出不含 API 和图片的 JSON 方案。个人数据不会写入分享压缩包。

## API 约定

默认按 OpenAI Images 兼容格式发送：

```json
{
  "model": "gpt-image-2",
  "prompt": "...",
  "n": 1,
  "size": "2048x1152",
  "quality": "high",
  "response_format": "b64_json"
}
```

支持以下常见响应：

- `data[0].b64_json`
- `data[0].url`
- `images[0].base64`
- `images[0].url`
- `output[0].image_base64`
- 顶层 `image_base64`、`image` 或 `url`

如果服务商字段不同，可以在“接口设置 → 高级设置”中添加额外请求参数和请求头。

### 悟空API创作台

悟空API的生图不是 `/v1/images/generations`，而是异步创作台协议。学员只需填写 `https://wkapi.work` 和自己的“生图组”Key，点击“检测连接”即可。系统内部会自动使用：

```text
Base URL: https://wkapi.work/api/v1/studio
产品 ID: image_gptImage2
输出比例: 16:9
```

实际生成流程为：

1. `POST /submit` 提交 `image_gptImage2` 任务。
2. 每 4 秒调用 `GET /poll?task_id=...&product_id=image_gptImage2` 查询状态。
3. 成功后下载结果 URL，并转成当前课件和 PPT 使用的本地图片数据。
4. 有参考图时，先通过 `/api/v1/ai/test-page/upload-image` 上传，再把返回的公网 URL 放入 `payload.urls`。

连接检测只读取 `/catalog`，不会生成图片或扣费；实际成功出图时按悟空控制台显示的产品单价扣费。悟空的 `size` 表示输出比例，因此工具会使用 `16:9`，不会发送 OpenAI Images 的像素尺寸或 `quality` 字段。

上传参考图后，系统改用 `multipart/form-data` 调用图片编辑端点，并按标准字段提交：

- `model`
- `prompt`
- `image[]`
- `size`
- `quality`
- `n`

这与 [OpenAI GPT Image 图片生成与编辑说明](https://developers.openai.com/api/docs/guides/image-generation)中的参考图工作流一致。第三方兼容服务是否支持，需要以服务商文档和实际测试为准。

## 重要说明

- 图片模型对中文小字和逐字准确性的控制仍可能出错，生成后应逐页检查。
- 参考图属于生成依据，不保证逐像素复刻；精确局部替换需要蒙版编辑。
- 参考图请求通常比纯文字生成消耗更多输入量，也可能更慢。
- 批量生成默认同时处理 4 页，可在生成页面切换为 2 / 4 / 6 张；接口繁忙或出现 429、503 时建议调回 2 张。
- 修改页纲后需要重新点击“识别页纲”。
- 修改参考图或逐页画面要求后，受影响的画面需要重新生成。
- 只有全部页面生成完成后才能导出，工具不会再生成缺页 PPT。
- 对某页效果不满意时，可以在该页卡片底部重新生成，不影响其他页面。
- 方案 JSON 保存项目名称、原始页纲、逐页画面要求和参考图应用范围，不保存 API、参考图或生成图片。
- 课件时光舱与方案 JSON 相互独立：方案适合跨电脑分享，时光舱适合在当前电脑恢复生成图片和重新下载。
- 本地服务只监听 `127.0.0.1`，不会直接暴露到局域网或公网。
